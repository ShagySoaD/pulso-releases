# PULSO 0.7.16

- Descargar actualización abre el enlace HTTPS oficial de la APK compatible en el navegador o manejador web elegido por Android. La instalación se realiza abriendo la descarga, sin desinstalar PULSO.
- Se retira el descargador e instalador interno de APK, incluida la comprobación que podía informar una firma distinta cuando no leía los certificados. Android sigue comprobando la firma durante la instalación.
- Se cancelan las tareas de descarga de APK pendientes de versiones anteriores. El aviso de actualización y su acceso directo a Ajustes se mantienen.
- Ya no se solicita el permiso para instalar paquetes desde PULSO. Android puede pedirlo al navegador o gestor de archivos que abra la descarga.
- Nueva pestaña Mensajes entre Biblioteca y Ajustes, con aviso «En construcción», adaptado al tema. No hay registro de usuarios ni chat operativo en esta versión.

Versión 0.7.16 / código 28, paquete y firma originales. Los usuarios de versiones anteriores deben instalar esta versión manualmente si su descargador interno falla. El nuevo recorrido se aplica a las futuras actualizaciones una vez instalada.
